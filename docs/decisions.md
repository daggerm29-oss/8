## Architecture Decision Log

(Deviations from or additions to `architecture.md`. Numbered `IMPL-ADR-n` to avoid clashing with architecture ADR-001…023.)

- Model router v1: tier comes from model-name tokens (not substrings: 'gemini' contains 'mini'); routing reorders the role chain only, never adds models outside it.
- Session replay: model turns served by a hidden 'replay' provider keyed per replay (model id = key); tools never run during replay, policy is still evaluated so allowed↔denied changes surface as divergence.
- 2026-11-08 F-AGT-5: hooks file is `.helix/hooks.json` (JSON, not YAML as in §9.7) to avoid a YAML dependency; hook output is always tainted/untrusted; hooks skipped on replay.
- F-REV-3 dep gate: only shell installs the agent runs are checked (no sandboxd shell-wrapper yet); OSV unreachable fails to ask, not allow.
- F-AUTH-1: keychain via OS CLIs (`security -i` stdin / libsecret `secret-tool` stdin), no native addon and no plaintext fallback; Electron binary is not fetched by workspace installs (`allowBuilds.electron: false`, run `pnpm --filter @helix/desktop setup`); headless smoke uses offscreen windows (native windows segfault under `--ozone-platform=headless`).
- NFR-6 Windows v0: verified only through Linux shims (no Windows host); WSL provider has no egress proxy or fs isolation yet (reports network: true so policy accounts for it); Credential Manager via PowerShell P/Invoke, no native addon.
- 2026-11-09 M2 review fixes: `reverify` checks shape + content hash before running any assertion command (tampered artifacts are rejected, nothing executes); plain-http forward proxy buffers bodies (≤4 MiB) and blocks any sentinel, TLS relay blocks foreign sentinels in non-text bodies too; dep gate parses every chained install, `npm ci`/bare install (package-lock versions), `pip -r` files, and asks (headless: denies) for installs it cannot resolve; replay keeps the recorded policy profile and answers approvals from the recording.
- M2 eval limits: cost reduction uses the fake Gemini provider and estimated tokens (not live billing); element→source 24/24 is a synthetic fixture and 6 text-only targets check the file but not the line, so it does not yet show ≥95% on real apps.
